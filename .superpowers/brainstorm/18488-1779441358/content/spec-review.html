mobile-db — Design Spec

Review and confirm before implementation plan. Reply in terminal with changes or approval.

Overview

Self-hosted JSON sync system. Single Go binary server + client library (mobile + web). Offline-first, CRDT merge, delta sync, encrypted everywhere. Designed for clean extensibility toward LoRa/IoT.

§2 — Data Model

Segregation Path
app_id → tenant (one SQLite file)
user_id → user within tenant (from JWT)
dataset_id → collection (one table)
doc_id → JSON document (independent CRDT)
Dataset ACL
RuleReadWrite
privateownerowner
sharedany userowner
publicno authowner
Schema Evolution
Client stores last_synced_schema_version locally.
Server response schema_version == local → incremental CRDT merge.
Server response schema_version > local → discard ops, request full snapshot, update local version.
Old ops never replayed against newer snapshot.

§3 — Auth Layer

Device Keys
1 active key per device
Stored: bcrypt hash
Header: X-Device-Key: id:secret
Registration: POST /devices/register
Rotation: atomic swap, instant
Remote wipe: DELETE /devices/:id
User JWT
Access: 15min TTL (HS256)
Refresh: 30d, one-time use
Reuse → revoke all tokens
Issued by: POST /auth/token
App validates user credentials
Server only signs the JWT
Admin Auth
HTTP Basic Auth + TLS
Password: bcrypt in env var
Session cookie: 1hr TTL
Rate limit: 5/15min/IP
Optional: IP allowlist
Separate from device/user auth

§4 — Sync Protocol

Wire Format
Encoding: CBOR (binary, IoT-friendly)
HTTP/2: CBOR + Zstd compression
LoRa: CBOR only (no Zstd overhead)

Client→Server: { clock, ops[] }
Server→Client: { new_clock, ops[], snapshot? }
Sync Flow
1. Write locally → CRDT op appended
2. POST /sync → CBOR+Zstd delta
3. Server: verify auth + ACL
4. Server: cr-sqlite CRDT merge
5. Server: compute diff by HLC clock
6. Server: respond with delta
7. SSE broadcast → other devices pull
Transport Interface (extensibility)
type SyncTransport interface {
    Receive(ctx context.Context) (<-chan SyncMessage, error)
    Send(ctx context.Context, msg SyncMessage) error
    Notify(ctx context.Context, appID, userID string) error
}
HTTP/2+SSE today · LoRa gateway in v2 · core never changes

§5–6 — Compaction & LoRa Fragmentation

Op Log Compaction
Trigger: ops > COMPACTION_THRESHOLD (default 1000)
1. Materialize snapshot from all ops
2. Write to snapshots table + HLC clock
3. Archive old ops (30d TTL then prune)
4. Cold sync: snapshot + tail ops
5. Client clock predates snapshot → full snapshot
LoRa Packet Fragmentation
Max payload: 51–242 bytes
Chunks: { frag_id, seq, total, data }
Reassembly: at gateway, before server
Core sync engine: never sees fragments
Lives entirely in transport/lora/

§12 — Deployment

Single Go binary. Zero runtime dependencies. Env vars:
ADMIN_PASSWORD_HASH=<bcrypt>
JWT_SECRET=<random 32 bytes>
DB_ENCRYPTION_KEY=<random 32 bytes>
BACKUP_DESTINATION=s3://my-bucket/mobile-db
LOG_LEVEL=info
COMPACTION_THRESHOLD=1000
Runs on any VPS, Docker, or bare metal. SQLite files on attached volume.
